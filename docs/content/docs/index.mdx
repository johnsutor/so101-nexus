**Record. Clone. Reinforce.** SO101-Nexus connects SO-100 and SO-101 leader arms,
LeRobot datasets, and Gymnasium simulation in one Python library.
Record demonstrations, train with behavior cloning, then fine-tune with reinforcement learning.

Start with [Installation](/docs/getting-started/installation), then run the
[Quickstart](/docs/getting-started/quickstart). No hardware is required for simulation.

## Start without hardware

Open the [BC + PPO Colab notebook](https://colab.research.google.com/github/johnsutor/so101-nexus/blob/main/examples/bc_ppo_warp_colab.ipynb).
Select a GPU runtime and run all cells to train with published demonstrations.

## Choose your task

[Environments](/docs/environments) lists the tasks, observations, rewards, and success conditions.
[Customization](/docs/concepts/customization) covers objects, cameras, and scene configuration.
